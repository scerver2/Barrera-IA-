Desenvolupament de les sessions

Desenvolupament de les sessions

Sessions 1-2: Introducció i Planificació

Objectiu: Presentar el projecte, formar equips i realitzar la planificació inicial.

1
Presentació del Projecte (20')

Vídeo inspirador sobre barres automàtiques i sistemes intel·ligents. Discussió sobre aplicacions reals.

2
Formació d'Equips (15')

Creació d'equips heterogenis de 3-4 persones. Assignació de rols inicials.

3
Brainstorming (25')

Pluja d'idees sobre funcionalitats de la barrera: tipus de sensors, mecanismes, disseny estètic.

4
Planificació (60')

Esbós del disseny, llista de materials necessaris, planificació temporal del projecte.

Producte de la sessió: Document de planificació i esbossos inicials del disseny.

Sessions 3-4: Introducció a Arduino

Objectiu: Aprendre els fonaments d'Arduino i la programació bàsica.

1
Components Arduino (20')

Identificació de components: placa Arduino, breadboard, cables, LEDs, resistències, sensors.

2
Primer Circuit (30')

Muntatge d'un circuit LED simple. Comprensió de connexions digitals i ground.

3
Programació Bàsica (40')

Introducció a l'IDE Arduino. Estructura d'un programa: setup() i loop().

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
4
Pràctica amb Sensors (30')

Lectura de sensors digitals (botons) i analògics (potenciòmetre).

Producte de la sessió: Circuit funcional amb LED i sensor, codi documentat.

Sessions 5-6: Control de Servomotors

Objectiu: Aprendre a controlar servomotors per al moviment de la barrera.

1
Teoria dels Servomotors (15')

Com funcionen els servomotors. Diferència entre servos estàndard i continus.

2
Connexió del Servo (20')

Muntatge del servomotor: cables de senyal, VCC i GND. Precaucions de seguretat.

3
Programació del Servo (30')

Ús de la llibreria Servo.h. Control de posició i velocitat.

#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  myServo.write(0);    // Barrera tancada
  delay(2000);
  myServo.write(90);   // Barrera oberta
  delay(2000);
}
4
Prototip de Barrera (55')

Construcció d'un prototip simple de barrera amb materials reciclats o cartró.

Producte de la sessió: Prototip funcional de barrera controlada amb servomotor.

Sessions 7-8: Integració de Sensors

Objectiu: Afegir sensors per detectar la proximitat de vehicles o obstacles.

1
Sensors Ultrasònics (25')

Funcionament del sensor HC-SR04. Càlcul de distàncies amb ones ultrasòniques.

2
Muntatge i Programació (40')

Integració del sensor ultrasònic al sistema de la barrera.

long duration;
int distance;

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  duration = pulseIn(echoPin, HIGH);
  distance = duration * 0.034 / 2;
  
  if (distance < 10) {
    myServo.write(90);  // Obrir barrera
  } else {
    myServo.write(0);   // Tancar barrera
  }
}
3
Proves i Ajustos (25')

Calibració del sensor. Ajust de distàncies i temps de resposta.

4
Millores Opcionals (30')

Afegir LEDs indicadors, buzzer sonor o pantalla LCD amb informació.

Producte de la sessió: Barrera amb detecció automàtica de presència.

Sessions 9-10: Intel·ligència Artificial

Objectiu: Integrar un model d'IA per a control per veu o reconeixement d'imatges.

1
Introducció a la IA (20')

Què és la intel·ligència artificial? Machine Learning i Deep Learning. Aplicacions reals.

2
Teachable Machine (30')

Introducció a Google Teachable Machine. Creació d'un model de reconeixement d'imatges o àudio.

🚀 Obrir Teachable Machine
3
Entrenament del Model (35')

Captura de dades (imatges de cotxes, targetes de proximitat, o comandes de veu). Entrenament i proves del model.

4
Integració amb Arduino (35')

Connexió del model d'IA amb Arduino mitjançant comunicació sèrie o Node.js. Processament de prediccions.

⚙️ Obrir Web serial Barrera IA
Nota tècnica: La integració d'IA pot requerir un ordinador intermediari o Raspberry Pi per processar el model i enviar comandes a Arduino via serial.
Producte de la sessió: Model d'IA entrenat i integrat al sistema de control de la barrera.

Sessions 11-12: Construcció Final i Millores

Objectiu: Finalitzar la construcció, optimitzar el sistema i preparar la presentació.

1
Millores Estructurals (30')

Reforç de l'estructura mecànica. Millora estètica del prototip.

2
Optimització del Codi (25')

Neteja i documentació del codi. Afegir comentaris explicatius.

3
Proves Finals (30')

Testing exhaustiu del sistema complet. Resolució d'errors (debugging).

4
Documentació (35')

Completar el dossier tècnic: esquemes, fotografies, codi font, memòria del projecte.

Sessions 13-15: Presentació i Avaluació

Objectiu: Presentar els projectes i realitzar l'avaluació final.

1
Preparació Presentació (30')

Creació de suport visual (PowerPoint, vídeo demostratiu). Assaig de la presentació oral.

2
Presentacions (90')

Cada equip presenta el seu projecte (10-15 min): demostració en viu, explicació tècnica, dificultats trobades i solucions.

3
Avaluació entre Iguals (20')

Els equips avaluen els projectes dels companys segons una rúbrica establerta.

4
Reflexió Final (20')

Debat grupal: què hem amb après? Quines aplicacions reals té? Com podem millorar?

Producte final: Barrera intel·ligent funcional + Dossier tècnic + Presentació oral
